GLIM_Test 개선본
실행
Windows의 Visual Studio 2022에서 GLIM_Test.sln을 엽니다.
C++를 사용한 데스크톱 개발과 MFC 구성 요소가 설치되어 있어야 합니다.
x64 / Debug를 선택해 빌드하고 실행합니다.
반지름(2~174)을 입력한 다음 DRAW를 누르면 원과 검출된 중심 좌표가 표시됩니다.
변경 사항
입력 칸에 독립적인 ID(IDC_EDIT_RADIUS)를 부여하고 빈칸, 0, 음수 및 이미지 밖으로 나가는 반지름을 검사합니다.
반지름에 맞춰 원 전체가 이미지 안에 들어오도록 중심을 선택합니다.
CImage의 행 간격(GetPitch)을 이용해 픽셀을 초기화하고 읽습니다.
중심 좌표 누적에 64비트 정수를 사용하며, 검출 실패 시 계산을 중단합니다.
빨간 십자선과 노란 표시 원을 이미지 창의 OnPaint에서 그려 창을 가렸다 다시 보여도 유지합니다.
이미지 창 생성 실패 시 메시지를 보여주고 종료합니다.
